Open-source desktop app · 2026

NeRoBoT

A desktop app that runs AI bots on several WhatsApp and Telegram accounts at once, each fully isolated.

I wrote a provider-agnostic AI layer: local models (Ollama, LM Studio, llama.cpp, vLLM), cloud APIs (OpenAI, OpenRouter, Groq, Together AI) and CLI agents (Claude Code, Codex, Gemini CLI) all work through one interface.

I added image, PDF and Word reading, AI image generation, per-user rate limiting and an admin panel.

A quick chat opens with a global shortcut, and the app updates itself through GitHub Releases.

AI visual novel engine · Sep 2026

RaiPy

A desktop app that turns a one-sentence idea into a Ren'Py game that compiles and runs. The user approves every stage.

It turns the idea into an outline, characters, locations, music and scene scripts. If you don't like a scene, you can have it rewritten with feedback.

Images are generated with embedded Python (diffusers), no external server. Loading and unloading models one at a time cut VRAM use on an 8 GB GPU from 7820 MiB to 3035 MiB.

A full run takes about 150 seconds. Some of the 614 tests run the Ren'Py output in the real engine. The app ships as a single 4.2 MB file.

  • 614 Test
  • 150 s End-to-end run
  • 7820 → 3035 MiB VRAM
  • 4.2 MB App size

Tauri v2, Rust, React 19, TypeScript, Python, diffusers, Ren'Py

Home-server assistant · Sep 2026

Heren Agent

A phone-first panel for running a home server and paired machines by voice or touch. Speech recognition and text-to-speech run fully on the local machine.

Heren is built on Hermes Agent: Hermes is the brain, Heren the face and hands.

Each machine runs a small Go agent. Agents sign their messages with ed25519 and use a one-time nonce against replay attacks.

Commands are grouped by risk: low-risk ones run at once, high-risk ones wait for approval in the UI, and critical ones are off by default.

  • ed25519 Signing
  • local STT + TTS Voice

Python, FastAPI, Go, TypeScript, faster-whisper, Piper TTS

  1. Title-deed check

  2. Live auctions

    Anti-sniping (a last-second bid extends the timer), race-safe bid handling and real-time updates over WebSocket.

Truva–Akınsoft arabirimi

Petra Cafe work, with Truva Teknoloji, 2026

A service that writes orders, cancellations and table moves from Truva's QR menu and waiter app into Akınsoft Wolvox Restaurant at the register within seconds.

A job log stops any order from being written twice; kitchen and bar tickets print automatically.

Recovers by itself after a register or internet outage; connects out over HTTPS only.
