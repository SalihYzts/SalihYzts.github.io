Software

Web, backend, desktop and AI: software I shipped.

MyEverythingList

An ad-free web app for tracking anime, manga, TV, films, games, books and music in one place. I built it on my own and shipped it in 19 languages.

YAZITAŞ · November 20268

Supabase with row-level security and Edge Functions; a Cloudflare Worker renders preview cards for shared links.

Search queries several sources and falls back when one goes down. IDs are matched across sources with Wikidata; the catalog grows by itself every night.

Imports from AniList, Steam, MyAnimeList, Goodreads and Letterboxd; follows, messages, reviews, badges and mini-games.

NeRoBoT

Open-source desktop app, 2026

A desktop app that runs AI bots on several WhatsApp and Telegram accounts at once, each fully isolated.

I wrote a provider-agnostic AI layer: Ollama, LM Studio, llama.cpp, vLLM, OpenAI, OpenRouter, Groq and agents like Claude Code, Codex and Gemini CLI all work through one interface. Updates itself through GitHub Releases.

  • 7 GitHub stars

RaiPy

AI visual novel engine, Sep 2026

A desktop app that turns a one-sentence idea into a Ren'Py game that compiles and runs. The user approves every stage.

Images are generated with no external server. Loading and unloading models one at a time cut VRAM use on an 8 GB GPU from 7820 MiB to 3035 MiB.

  • 614 Test
  • 150 s End-to-end run
  • 7820 → 3035 MiB VRAM
  • 4.2 MB App size

Tauri v2, Rust, React 19, TypeScript, Python, diffusers, Ren'Py

YAZITAŞ · November 202610

Parsel

Internship project, Stoneograph, Aug 2026

A land marketplace with title-deed verification and live auctions.

A “title-verified” badge that looks parcels up in Turkey's land registry (TKGM), plus slope-corrected area and elevation analysis.

Anti-sniping (a last-second bid extends the timer), race-safe bid handling and real-time updates over WebSocket.

A pipeline that renders narrated, subtitled virtual drone videos over a 3D map (Playwright, ffmpeg).

  • ~10k lines Backend code
  • 103 Test

Python, FastAPI, SQLAlchemy, WebSocket, Shapely, pyproj, JavaScript

Heren Agent

Home-server assistant, Sep 2026

A phone-first panel for running a home server and paired machines by voice or touch. Speech recognition and text-to-speech run fully on the local machine.

Each machine runs a Go agent. Agents sign messages with ed25519 and use a one-time nonce against replay attacks. High-risk commands wait for approval in the UI.

  • ed25519 Signing
  • local STT + TTS Voice

Python, FastAPI, Go, TypeScript, faster-whisper, Piper TTS

Kafe Finans

Petra Cafe work, desktop app, 2026

An income, expense and revenue app for the cafe. It checks hand-entered revenue against the POS end-of-day totals day by day and reads POS deposits and fees from bank statements.

Runs on the register PC; phones connect over VPN with a PIN.

Every name and amount in the screenshot is made-up demo data.

  • 240 Test

Electron, React, TypeScript, SQLite, Vitest

Truva–Akınsoft arabirimi

Petra Cafe work, with Truva Teknoloji, 2026

A service that writes orders, cancellations and table moves from Truva's QR menu and waiter app into Akınsoft Wolvox Restaurant at the register within seconds.

A job log stops any order from being written twice; kitchen and bar tickets print automatically.

Recovers by itself after a register or internet outage; connects out over HTTPS only.

  • ~3,600 lines Go code
  • one Windows service Runs as

Go, Windows Service, HTTPS, Akınsoft Wolvox
